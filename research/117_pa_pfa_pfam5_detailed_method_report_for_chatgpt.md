# P_A、P_FA 与 P_FAM5：方法原理、完整算法和实验状态报告

日期：2026-09-18  
用途：本文件是自包含技术材料，可直接提供给ChatGPT或其他研究人员进行理论与实验审查。

## 1. 研究问题与观测模型

研究场景为近场宽带单用户角度--距离定位。当前证据只针对同步、LoS单径、条件仿真模型。

### 1.1 完整复频谱观测

对第`m`个子载波，定义已知波束与候选位置响应的复内积

`q_m(theta,r)=b_m^H a_m(theta,r)`，

标量观测为

`z_m=beta q_m(theta,r)+n_m`，

其中`beta`是跨频公共未知复增益。给定`(theta,r)`后解析消去`beta`，得到归一化集中得分

`J_z(theta,r)=log(|q^H z|^2/(||q||^2 ||z||^2))`。

该得分保留完整子载波复数形状和相对相位；若每个子载波都有任意独立的复增益，则标量`z`
中的角距通常不可辨识。

### 1.2 原始阵列观测

第`m`个载波的`N=256`阵列快照采用条件模型

`y_m=alpha_m a_m(theta,r)+w_m`，

其中`alpha_m`为逐载波未知复增益。它可吸收每载波公共相位，但不能吸收阵元间空间相位。
P_A与P_FA对该阵列观测采用不同的角度统计。

## 2. 三种方法共享的L06前端

三种方法都从同一个有限完整频谱前端开始：

1. 从峰值载波附近构造五个角度锚点，偏移为`[-0.2,-0.1,0,0.1,0.2] deg`；
2. 使用513个稀疏载波和0.1 m距离间隔生成二维候选；
3. 保留8个候选；
4. 使用全部2048个载波和精确球面`q(theta,r)`最多细化10次；
5. 输出前端中心`(theta_F,r_F)`和峰值载波索引。

L06是有限多起点集中复谱搜索，不是全局最大似然证书。后续三个方法都继承其局部支持风险。

## 3. 方法P_A

### 3.1 计算图

`L06 front -> L160 spatial-smoothed 1-D MUSIC angle -> local q-only range profile`。

P_A是当前论文主方法与主攻击依据。

### 3.2 一维MUSIC角度阶段

固定前端距离`r_F`，选择`K=2047`个载波。对每个载波：

1. 使用`L=160`阵元子阵，共`P=N-L+1=97`个重叠子阵；
2. 按`(theta_F,r_F)`执行几何相位对齐；
3. 构造`160 x 160`平滑协方差；
4. 使用直接EVD提取主信号向量`u_m`；
5. 对候选角度计算

`J_A(theta;r_F)=(1/K) sum_m -log(max(1-|u_m^H a_m(theta,r_F)|^2,epsilon_0))`。

角度只在`[theta_F-0.2,theta_F+0.2] deg`与物理域的交集内搜索。采用`41/31/21`点三级
网格，每一级围绕前一级最佳点缩小范围，总计93个MUSIC角度评分点。距离在此阶段固定为`r_F`。

### 3.3 条件距离阶段

固定MUSIC角度`theta_A`，最大化

`J_P(r|theta_A)=log(|q(theta_A,r)^H z|^2/(||q(theta_A,r)||^2||z||^2))`。

搜索区间为`[r_F-2,r_F+2] m`与`[15,50] m`物理域的交集；粗间隔不超过0.05 m，至少40个
区间，保留8个局部峰和所有已评价最佳候选，再用`fminbnd`连续细化，`TolX=1e-6 m`。

最终输出`(theta_A,r_A)`。`lambda=1`，没有MUSIC/profile混合权重。

### 3.4 方法作用

- 将Zhang-style局部二维MUSIC改成固定距离的一维MUSIC角度和条件复谱距离；
- 说明“联合二维MUSIC”不是高精度角距估计的必要结构；
- 利用完整`q`频谱缓解极窄二维MUSIC距离窗的边界和失捕；
- 仍保留空间平滑、协方差和EVD，因此不能用P_A自身攻击空间平滑孔径损失。

### 3.5 最终证据

R34使用200个新位置、七个SNR`-10:-5:20 dB`，共1400个独立trial：

- 七SNR角度均建立相对C_enhanced的预声明非劣；
- P_A和C在1398/1400行角度完全相同；
- 距离RMSE七SNR点估计均更低，降低3.05%到49.63%；
- 同时校正后，在0、15、20 dB建立距离统计优效，其余SNR仅为数值改善；
- 七SNR均无大于1 m的P_A距离失捕；
- 冻结实现中相对同配置C_enhanced平均运行时间降低约50.19%。

因此P_A拥有三种方法中最成熟的整体角距证据。

## 4. 方法P_FA

### 4.1 计算图

`L06 front -> N256 full-array conditional projection angle -> same local q-only range profile`。

P_FA不是P_A的后处理，也不执行一次P_A。它从L06前端直接进入完整孔径角度估计。

### 4.2 完整孔径集中角度目标

固定前端距离`r_F`，对`K=2047`个载波采用

`y_m=alpha_m a_m(theta,r_F)+w_m`。

单位范数导向矢量下，逐载波复增益的最小二乘解为

`alpha_hat_m=a_m^H y_m`，

集中残差为

`E_Y(theta|r_F)=sum_m (||y_m||^2-|a_m^H y_m|^2)`。

因此P_FA最大化

`S_FA(theta|r_F)=sum_m |a_m(theta,r_F)^H y_m|^2 / sum_m ||y_m||^2`。

它使用完整`N=256`阵元，不构造协方差、不做空间平滑、不做MUSIC或EVD。搜索区间仍为
`theta_F+-0.2 deg`，先评价41点网格，再在最佳网格点相邻区间使用`fminbnd`；最终候选分数
不得低于已评价网格最佳值。

### 4.3 nuisance不变性

若每个载波整列乘以任意公共相位`exp(j phi_m)`，则

`|a_m^H exp(j phi_m)y_m|^2=|a_m^H y_m|^2`。

所以该角度目标对公共时延导致的每载波公共相位旋转严格不变。它不对阵元相关相位误差、阵列
校准误差、CFO列内失配或多径不变。

### 4.4 Fisher信息解释

解析消去复增益后，单载波角度等效Fisher信息为

`J_theta_theta^(m)=2|alpha_m|^2/sigma_m^2 * ||Pi_m_perp partial_theta a_m||^2`，

其中`Pi_m_perp=I-a_m a_m^H/(a_m^H a_m)`。远场居中ULA主项下，几何信息与
`N^2-1`成正比。只比较孔径项，N256相对L160的信息比约为

`(256^2-1)/(160^2-1)=2.5601`，

相应理想局部标准差下限比约为`0.625`。这不是实际MSE必然改善37.5%的定理，因为P_A还包含
空间平滑、相关子阵和有限样本统计。

### 4.5 距离阶段

P_FA把`theta_FA`代入与P_A完全相同的`+-2 m` q-only profile。它没有提出新的距离统计。
因此角度更准并不保证距离逐样本更准：带噪q-profile可能在新角度下选择更远的竞争峰，P_A的
小角度误差有时反而会偶然补偿距离误差。

### 4.6 实验证据

R45 calibration-600显示：

- 聚合角度MSE相对P_A约为0.437；
- 距离MSE约与P_A相同；
- 完整独立入口相对P_A平均快约46.43%；
- 校准门槛通过，因此进入R46最终试验。

R46使用200个新位置、七SNR、1400行：

- 七SNR角度优效家族7/7通过；
- 聚合角度MSE比`0.425680`，角度RMSE改善`34.76%`；
- 聚合距离MSE比`1.006987`，普通cluster bootstrap `U95=1.023008`；
- 七SNR同时距离非劣家族未通过，联合主要终点失败。

因此P_FA是已经最终确认的角度/完整孔径机制方法，但不能整体替代P_A成为主角距方法。

## 5. 方法P_FAM5

### 5.1 与P_FA的关系

P_FAM5完整执行P_FA的L06前端和N256角度估计，角度输出与P_FA逐行完全相同。它只替换
P_FA最后的硬角度距离profile：从`r_hat(theta_FA)`改为对局部角度不确定性积分后的距离profile。

它不是P_A与P_FA的组合，不执行P_A、MUSIC或EVD。更准确地说，P_FAM5是P_FA的距离后端
扩展/后处理。

### 5.2 局部角度方差

在P_FA角度`theta_FA`和前端距离`r_F`处，对原始阵列集中残差`E_Y(theta)`使用中心差分：

`E_theta_theta ~= [E(theta-h)-2E(theta)+E(theta+h)]/h^2`，

其中`h=1e-4 deg`。自由度设为

`nu=K(N-1)`，

局部观测信息近似给出

`sigma_theta^2=E_Y(theta_FA)/(nu E_theta_theta)`。

最终标准差裁剪到`[1e-6,5e-3] deg`；若曲率非正、非有限或残差非法，则使用最大值
`5e-3 deg`。这是局部高斯/Laplace型近似，不是严格的有限样本后验定理。

### 5.3 五点Gauss-Hermite角度边缘化

采用标准正态五点节点

`[-2.8569700139,-1.3556261800,0,1.3556261800,2.8569700139]`

和权重

`[0.0112574113,0.2220759220,0.5333333333,0.2220759220,0.0112574113]`。

角度节点为

`theta_i=clip(theta_FA+sigma_theta x_i,theta_min,theta_max)`。

对每个`(theta_i,r)`，先解析消去q观测的公共复增益：

`E_z(theta_i,r)=||z||^2-|q(theta_i,r)^H z|^2/||q(theta_i,r)||^2`。

采用未知噪声尺度的集中复高斯形式

`ell_i(r)=-(M-1)log(max(E_z(theta_i,r),E_floor))`，

再计算

`ell_marg(r)=log sum_i w_i exp(ell_i(r))`。

距离仍只在`[r_F-2,r_F+2]`物理裁剪区间内，用与P_A/P_FA相同的网格、8峰保留和连续细化。

### 5.4 实验证据

R47开发60行在P_FAM3和P_FAM5中选中P_FAM5；相对P_A聚合距离MSE比约`0.999847`。
但P_FAM5相对硬P_FA的距离RMSE只改善`0.000734%`。

R48使用另外200个位置、600行：

- 相对P_A聚合距离MSE比`0.999953`，bootstrap `U95=1.000155<1.02`，非劣通过；
- 相对硬P_FA聚合比`0.999954`，但`U95=1.000014>1`，未证明优效；
- holdout-540得到相同失败；
- P_FAM5与P_FA距离输出的RMS差只有`2.15e-5 m`，即`0.0215 mm`；
- `calibrationReady=false`，未进入最终试验。

失败原因是599/600行局部角度后验极窄，五个节点都落在同一个P_FA角度模式中；积分仍由与
硬代入相同的q距离峰主导。唯一灾难样本的真值角度位于整个局部区间之外，局部高斯边缘化
无法发现另一个模式。

## 7. 对Zhang2026攻击的解释力

### P_A最强的部分

1. 峰值子载波索引不能唯一表示连续二维位置；
2. 极窄局部二维MUSIC距离窗不能保证粗估计失捕后的恢复；
3. 一维MUSIC角度加完整q条件距离已经能在独立1400行中获得成熟角距结果；
4. 因此“二维联合MUSIC”不是消除局部支持和距离误差的充分条件。

### P_FA新增的部分

1. L160空间平滑造成有效孔径损失；
2. 即使消去逐载波未知复增益，完整N256阵列仍保留强角度信息；
3. covariance、MUSIC和EVD并非获得更好角度的必要结构；
4. 但这些新增解释不能替代P_A成熟的距离证据。

### P_FAM5能说明和不能说明的部分

P_FAM5说明：普通样本中P_FA角度后验已经极窄，局部角度方差并不是P_FA距离差异的主要来源。
它不能说明角度边缘化改善距离，也不能增加对Zhang2026的主攻击强度。

## 8. 共同限制

- L06和局部角窗都可能排除真值；
- P_A/P_FA/P_FAM5的距离profile都假定公共时延已校准；
- `z`使用精确球面响应，`Y`使用Fresnel响应，两块不是统一似然；
- 当前没有真实RF时隙、总能量、路径损耗和硬件成本公平核算；
- 不支持异步、多径、阵列误差、CFO或真实硬件鲁棒性结论；
- C_enhanced是本项目的Zhang-style同条件增强基线，不是作者真实代码。
