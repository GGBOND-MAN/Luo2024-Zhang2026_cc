# R47-R48：P_FA 角度边缘化距离方法结果审计

日期：2026-09-18  
方法：`P_FAM5`，即保持 P_FA 角度输出不变，对 q 距离似然在局部角度后验上作五点 Gauss-Hermite 边缘化  
结论：**R47 pilot 入选；R48 calibration 未通过；停止该候选，不进入最终实验**

## 1. 实验身份与完整性

R47 使用20个全新位置、`-10/0/20 dB`，共60行开发数据；R48 使用另外200个全新位置、
同样三个SNR，共600行，其中前60行为诊断集，后540行为冻结holdout。R48没有读取或执行
R34、R41、R46的最终trial，也没有在600行结果上调整GH节点、权重、角度方差或门槛。

R48最终状态：

- 600/600行成功，0失败；
- source digest：`c0eed77f13d952fdeb406d282bfff0fe23a6cd2dc220173fc3fd52cfc991ff2f`；
- 当前源码摘要与保存摘要完全一致；
- 决策表、all-600和holdout-540的10,000次位置簇bootstrap均可逐值重放；
- 角度与P_FA逐行完全相同，Gram=0，fallback=0；
- 修改后的运行器Code Analyzer为0 issue，R48测试4/4通过。

第一次R48执行在272行后发生checkpoint覆盖写入失败。该目录已原样归档，且未读取其中性能
结果。随后只修改持久化机制：由覆盖单一checkpoint改为只写新的版本化checkpoint；方法、
设计、seed和统计规则均不变。第二次从零运行相同冻结600行并完整结束。因此该工程故障没有
形成基于中间性能的选择或调参。

## 2. R47 pilot

R47同时比较三点和五点Gauss-Hermite版本。两者对P_A的聚合距离MSE比都约为
`0.999847`，最大逐SNR比约为`1.01569`，按预声明排序选中P_FAM5并通过pilot门槛。

但是，P_FAM5相对硬代入P_FA的聚合距离MSE比为`0.999985`，距离RMSE仅改善
`0.000734%`。60行角度曲率全部有效，角度标准差中位数仅`2.97e-4 deg`。因此pilot
虽然形式通过，但已经显示边缘化对距离解的实际扰动极小。R48设置“相对硬P_FA的bootstrap
上界必须小于1”，正是为了区分真实机制改善和数值级微扰。

## 4. 为什么边缘化几乎不起作用

P_FAM5与硬P_FA的距离估计差异非常小：

- 600行RMS位移：`2.15e-5 m`，约`0.0215 mm`；
- 平均绝对位移：`4.91e-6 m`；
- 最大绝对位移：`4.57e-4 m`；
- 逐SNR RMS位移为`0.0368/0.00611/0.000600 mm`。

其原因不是五点求积精度不足，而是当前建模结构决定的：

1. 599/600行的局部角度后验极窄，`sigma_theta`中位数仅`2.81e-4 deg`；
2. q观测维度高，集中似然随角度和距离变化尖锐；
3. 局部高斯后验的GH节点均落在同一个P_FA角度模式附近；
4. 积分仍由与硬代入相同的距离峰主导，所以只产生微米到亚毫米级移动；
5. 增加GH节点只能更精确地积分同一个局部模式，不能发现区间外的正确角度模式。

因此R48否定的是“围绕单一P_FA局部角度解作局部高斯边缘化，可以稳定改善距离”这一
机制假设，而不是否定角度不确定性本身对距离的重要性。

## 5. `positionId=124, -10 dB`异常机制

该行为600行中唯一的无效曲率样本，也是唯一的P_FA角度搜索边界命中：

| 项目 | 数值 |
|:--|--:|
| 真值角度/距离 | `-6.397517 deg / 15.422643 m` |
| L06前端角度/距离 | `-5.780945 deg / 34.363331 m` |
| P_FA角度区间 | `[-5.980945,-5.580945] deg` |
| P_FA/P_FAM5角度 | `-5.980945 deg`，命中下边界 |
| P_FA距离 | `34.914521 m` |
| P_FAM5距离 | `34.914063 m` |
| P_FAM5距离误差 | `19.491421 m` |
| 曲率状态 | `invalid-curvature-maximum-sigma` |

真值角度在P_FA局部搜索区间之外约`0.4166 deg`。因此P_FA被前端错误模式限制在错误候选区间，
P_FAM5再围绕该错误局部解作边缘化也不可能恢复真值。硬P_FA、P_A和G在该行的距离均约
`34.9145 m`，说明这不是边缘化新引入的失败。

该单行贡献P_FAM5在`-10 dB`距离平方误差总和的`98.68%`，也贡献all-600总距离平方误差
的`98.67%`。去掉该行只可作为机制诊断，不能改变正式门槛；它说明当前下一问题是低SNR
多模式/候选区间恢复，而不是距离profile端点截断，也不是GH5求积误差。

## 6. 对P_A、P_FA与Zhang2026攻击的含义

1. P_A仍应作为主方法和主距离攻击依据；R48没有提供替代其最终地位的新证据。
2. P_FA仍保留R46已经建立的角度优效和完整孔径机制解释力；P_FAM5不改变P_FA角度，因此
   不增加新的角度或孔径攻击证据。
3. P_FAM5相对P_A距离非劣，但没有相对硬P_FA的统计优效，不能作为独立增强方法写入主结论。
4. R48进一步支持一个更精确的机制表述：完整孔径角度估计通常非常尖锐；距离失败主要来自
   条件q-profile的峰选择以及少数前端错误模式，而不是一般性的局部角度方差传播。
5. 对Zhang2026的核心攻击仍由P_A/P_FA承担：L160平滑孔径和二维MUSIC并非必要；但R48不能
   被用来宣称“贝叶斯角度边缘化进一步提升了距离”。

## 7. 下一轮实验方向

停止P_FAM5路线，不在R48上调整节点或方差。下一轮应建立新的开发协议，研究
**多候选全孔径角度--距离联合重排**，而不是单局部高斯边缘化：

1. 从L06前端或扩展全孔径角度扫描中保留多个分离候选，而非只保留一个`+-0.2 deg`区间；
2. 对每个候选独立执行全孔径角度细化和q距离profile；
3. 使用预先定义的联合证据或留一载波验证分数选择候选，禁止用真值和R46/R48结果调规则；
4. 首先用全新开发数据检查能否救回“真值位于原局部区间外”的样本，同时不破坏普通样本；
5. 必须报告错误模式恢复率、错误切换率、角度与距离MSE、尾部P95/P99和计算量；
6. 只有在新校准集上同时证明相对P_A非劣、相对硬P_FA有实质且统计稳定的改善，才进入新的
   独立最终实验。

这一路线直接处理R48暴露的搜索支持问题，也仍保持“无二维MUSIC、完整孔径、顺序估计”的
攻击结构。若多候选选择需要重新执行完整P_A MUSIC/EVD，则会削弱P_FA的独立机制价值，故
下一轮首选不调用P_A的候选生成和重排规则。
