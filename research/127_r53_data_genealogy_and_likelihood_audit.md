# R53：Y/z数据谱系与似然合法性审计

日期：2026-09-18  
状态：**STATISTICAL_MODEL_GATE = PASS，物理同源解释受限**

## 1. 代码谱系

当前仿真在 fsjad.replayRound27Data 中先生成标量观测：

1. 精确球面响应 q(theta,r)；
2. 一个公共复增益 beta；
3. M维独立复高斯噪声；
4. 得到 z=beta*q+n_z。

随后同一个确定性随机流继续进入 jad.simulateSnapshots，按载波生成N维阵列噪声和Fresnel阵列观测Y。
两块使用随机流中顺序、不重叠的随机抽样；共用seed并不表示共用噪声样本。

## 2. 审计回答

| 问题 | 结论 |
|---|---|
| z是否由保存Y确定性投影得到 | 否 |
| 是否共享同一个噪声样本 | 否 |
| 是否使用同一个随机流 | 是，抽样区间不重叠 |
| 条件于theta、r后噪声是否独立 | 在当前仿真生成模型中是 |
| 两块是否分别归一化 | 是 |
| Y噪声结构 | 天线和载波间独立同方差复高斯，方差为SNR规则确定值 |
| z噪声结构 | 载波间独立同方差复高斯，方差按精确q平均能量归一化 |
| 能否写成条件乘积 | 当前仿真中可以 |
| 是否证明真实接收机中也是两份独立观测 | 否 |

因此本轮允许使用

\[
p(Y,z\mid\theta,r)=p(Y\mid\theta,r)p(z\mid\theta,r),
\]

但结论必须限定为“当前混合仿真模型下的条件乘积似然”。

## 3. 物理解释限制

当前z使用精确球面响应，Y使用Fresnel响应；两者分别由仿真器独立合成，并非同一接收数据的
确定性变换。因此：

- R53不会增加P_FA相对于当前仿真输入的数据源；
- 但不能把R53结果直接解释为真实系统中同一噪声观测的无损联合似然；
- 若实际系统满足 z=b^H Y，则两块不独立，当前相加公式不能直接用于真实系统。

## 4. 集中似然自由度

对 y in C^n, y ~ CN(X beta, sigma^2 I)，同时极大化beta和未知sigma后：

\[
\ell_{ML}=-n\log(RSS/n)+C.
\]

所以本轮严格使用：

- z块：n_z=M=2048；
- Y块：n_Y=NK=256*2047。

不使用 M-1 与 K(N-1)。若使用残差自由度形式，必须改为另一种限制或积分似然并补充
设计矩阵行列式，特别是z块的 q^Hq 会随距离变化，不能省略。

## 5. 插件角度限定

theta_FA本身由Y估计，随后Y再次进入距离目标。因此P_FALF是顺序式
conditional plug-in concentrated likelihood fusion，不是把外部已知角度代入后的完整联合ML。
本轮不经验扣除一个角度自由度，也不把方法表述为全局二维联合最大似然。
