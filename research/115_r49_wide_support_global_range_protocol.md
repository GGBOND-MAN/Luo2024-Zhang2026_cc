# R49：宽角度支持与全局 q 距离 Profile 开发协议

日期：2026-09-18  
版本：`R49-PFA-wide-support-global-range-pilot60-v1`  
证据角色：R48之后的新开发实验，不是校准或最终证据

## 1. 目标

R48证明局部角度高斯边缘化几乎不改变P_FA距离，并暴露了一个“真值位于P_FA局部角度
区间之外”的灾难性样本。R49检验一种仍保持顺序结构的支持恢复方法：

`L06 front -> 宽支持N256 raw-array角度 -> 全物理距离域q-only profile`。

该方法不执行P_A、空间平滑、MUSIC、covariance或EVD，也不构造z/Y联合目标。

## 2. 冻结候选

- `P_FAW06`：以L06输出为中心，在物理域交集内搜索`+-0.6 deg`；
- `P_FAW10`：对应`+-1.0 deg`；
- 两者角度网格间隔均为`0.01 deg`，保留所有已评价候选中的最大raw-array VPML分数；
- 角度确定后，在`[15,50] m`上用350个区间、8个局部峰运行一次完整q-only profile；
- L06距离作为额外可行候选保留，但不限制搜索区间。

P_FA和P_FAM5作为同观测参照，P_A和C_enhanced只在估计器外作为配对基线。

## 3. 新数据与旧压力测试

- 20个全新位置，`-10/0/20 dB`，共60行；
- position seed `64000000`，trial root `64100000`；
- 不读取R34/R41/R46/R48最终估计行；
- `R48 positionId=124,-10 dB`仅从冻结设计重建观测并作标注压力测试，不进入候选选择、
  MSE、门槛或停止判断。

## 4. 选择与停止规则

候选首先最小化相对P_A的最大逐SNR距离MSE比，然后比较聚合距离比、聚合角度比和较窄支持。
入选候选必须同时满足：

1. 最大逐SNR角度MSE比不超过`1.05`；
2. 聚合角度MSE比不超过`0.85`；
3. 最大逐SNR距离MSE比不超过`1.05`；
4. 聚合距离MSE比不超过`1.00`；
5. 60行全部成功且输出有限。

任一条件失败即停止，不改变支持宽度、全局距离网格、候选数或门槛，也不进入扩大校准。
