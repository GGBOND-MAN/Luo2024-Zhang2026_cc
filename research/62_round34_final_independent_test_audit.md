# Round34 最终独立试验：结果、身份审计与结论边界

日期：2026-09-11  
分析版本：`R34-frozen-final-posthoc-analysis-v1`  
数据目录：`server_packages/round34_final_authorized_full_project_upload_20260911_115954`

## 1. 总结结论

Round34 的 1400 个冻结 trial 已全部完成。原始数据、分片、求解器身份、源码摘要、设计哈希和
冻结统计重算均通过关键完整性审计。P_A 相对同前端 `C_enhanced`：

- 七个 SNR 的角度 MSE 均达到预声明的统计非劣标准；
- 七个 SNR 的距离 RMSE 点估计均更低，降低 3.05%–49.63%；
- 经过七个 SNR 的同时多重比较校正后，只能在 0、15、20 dB 声明距离 MSE 统计优效；
- 在 -10、-5、5、10 dB，距离数值更好，但统计优效没有建立；
- 冻结 R33 同机完整在线计时中，P_A 比同样优化的 `C_enhanced` 快 50.1923%，但仍是
  `C_public` 的 2.2453 倍；这不是相对 Zhang2026 作者完整程序的速度结论。

本批结果支持“局部联合 MUSIC 并不足以消除所有距离误差来源”，但不能支持“MUSIC 普遍错误”
或“纯目标函数在相同信息下必然更优”。P_A 与 C 使用不同距离搜索域及不同距离统计信息。

### 2.2 流程偏差：必须披露

服务器 1 的授权后预检完整通过：14 项 R34 专项、174 项全项目回归、Code Analyzer 0 项，
并确认运行前无最终结果目录。

服务器 2 的授权后预检没有 PASS 标志，最终停止于：

```text
A final-test result folder already exists before shard execution.
```

因此“两个服务器都在空结果目录上完成授权后预检”这一执行流程要求没有完全满足。不能事后把
该预检写成通过。另一方面，分片 runner 自身再次校验授权、源码、设计和 shard 身份，checkpoint
恢复也校验设计；最终两片互斥完整、输入哈希和求解器身份一致，未发现旧数据混入、seed 替换或
算法漂移。因此当前判断是：**数值结果和冻结推断可使用，但应在内部审计/复现材料中明确记录该
流程偏差**，不建议为了“洗掉”偏差而重跑或覆盖原结果。

Shard 1 的日志第一条进度为 64/700，而 BatchSize 为 32，说明它很可能从已有 32 行 checkpoint
机械续跑；这是冻结协议允许的恢复方式，并且 `loadCheckpoint` 的身份和设计检查已通过。服务器 2
预检发现已有结果目录也更可能与先创建的 checkpoint/运行目录有关，但现有日志不足以证明目录最初
由哪一次命令创建，因此这里只作解释性推断，不把它写成已证实事实。

另一个非数值问题是 aggregate 的 `identity` 字段沿用了准备阶段元数据，仍显示
`authorized=false, trialsExecuted=0`。聚合器实际在入口调用了正式授权断言，授权文件也与当前
source/design 精确绑定，因此它是 provenance 元数据未更新，而不是未授权运行。原 MAT 不覆盖，
应连同授权文件和本报告的修订审计一起归档。

## 4. 尾部、P95 和失捕

P_A 的距离 P95 在 -10/-5/0/5/10/15/20 dB 分别为：

`0.266387, 0.0988002, 0.0236085, 0.0123712, 0.00726155, 0.00458119, 0.00233376 m`。

P_A 在七档 SNR 上均无大于 1 m 的距离失捕。`C_enhanced` 仅在 -10 dB 有 2/200（1%）失捕，
其余 SNR 为 0。

- -10 dB：C 的最大距离误差为 1.91111 m，P_A 最大为 0.665630 m；C 的最大 10% 用户贡献
  84.30% 的距离 SSE，P_A 为 67.45%。
- 0 dB：C 的最大 10% 用户贡献 83.15%，P_A 为 63.37%。
- 高 SNR 下 P_A 总 MSE 更低，但 SSE 集中度并非总更低：15/20 dB 的 P_A 最大 10% 贡献
  44.48%/48.76%，C 为 37.54%/30.26%。因此不能写成 P_A 在所有 SNR 都普遍“改善尾部形态”。

一个具有解释力但不能当总体证明的样本是 `seed=52100034`：真实距离约 16.953 m，L06 前端
给出 15.0398 m 且达到迭代上限；C 的 ±0.0025 m 局部距离域输出 15.0423 m，误差 1.9111 m；
P_A 的裁剪后 ±2 m profile 输出 16.8842 m，误差 0.06918 m。它直接展示了“共享前端失捕后，
极窄局部联合搜索无法恢复，而较宽复谱 profile 可以恢复”的机制，但不能据单个样本宣称全局
MUSIC 缺陷。

## 6. C_public 与复杂度

`C_public` 是透明公开假设基线（K=5、L=128、本项目明确窗口和网格），不是 Zhang2026 作者
完整实现。其距离 RMSE 从 -10 到 20 dB 为 0.9601、0.9308、0.8449、0.7534、0.5725、
0.4591、0.2738 m，显著差于 P_A；但这只能说明该透明低成本配置在当前条件模型上精度不足。

冻结 R33 同机完整在线计时：

| 方法 | 平均完整在线时间 (s) | 0 dB 距离 RMSE (m) |
|:---|---:|---:|
| C_public | 4.06760 | 0.844860 |
| H_A | 8.45855 | 0.0238807 |
| P_A | 9.13305 | 0.0140372 |
| C_enhanced | 18.33664 | 0.0234955 |

P_A 相对 `C_enhanced` 时间降低 50.1923%，比 H_A 慢约 7.98%，并是 C_public 的 2.2453 倍。
该时间来自冻结的单方法在线计时，不使用服务器吞吐量。它是实现级收益，不是理论阶数下降，
也不能替代作者真实程序的复杂度对照。

## 7. 对攻击主线的最终支持程度

当前最稳妥的论文主张是：

1. 联合角距 MUSIC 避免了把一个固定角度点机械传给距离搜索，但若它仍依赖局部前端中心、
   极窄距离域、冻结补偿/子空间和有限谱面搜索，则距离误差仍可能由窗口截断、边界和局部曲率
   产生；“联合”本身不是消除全部级联或局部化误差的充分条件。
2. 在当前同步单径条件 `z+Y` 模型中，P_A 保持几乎相同的角度结果，用条件全复谱 profile
   降低距离 RMSE；独立最终数据在 0、15、20 dB 建立了统计优效，在其余点只建立数值改善。
3. 该比较同时改变了距离搜索域和距离统计信息，不能被表述为“相同信息下纯目标函数战胜
   MUSIC”。也不能把 `C_enhanced` 当成 Zhang2026 作者真实实现。
4. P_A 不是普遍优于 H_A：profile 在高 SNR 略微退化，因此不能声称条件 profile 对所有
   信噪比都必然有益。

## 8. 理论与模型审查结论

没有发现会推翻本轮数值结论的公式或实现错误：

- profile 评分是消去跨频公共复增益后的归一化集中复谱评分；
- A-only 正式路径显式固定 q-only 响应与直接协方差 EVD；
- P_A 角度入口不读取 C 的最终答案；
- 位置误差由极坐标估计转换到二维位置后计算；
- bootstrap 按 positionId 整簇、七档 SNR 共用重采样索引，并使用修正后的列保持实现；
- 两个主家族分别进行单侧同时上界判断。

需要保留的表述限制：当前 `simultaneousUpper` 更准确地称为“使用 bootstrap 标准差标准化的
max-statistic 同时上界”，不宜强调为具有每次重采样标准误的完全 studentized bootstrap-t。
这属于术语精度，不改变已冻结的估计量和本轮判断。

模型仍限于同步、LoS 单径、条件 `z+Y` 仿真；`z` 使用精确球面响应，`Y` 使用 Fresnel 模型及
独立噪声，两路观测没有统一的真实 RF 时隙/总能量核算。已有 ±0.1 ns 检查显示约 ±0.03 m
距离平移，因此必须明确公共时延已校准。不得把当前结果写成异步、多径、真实硬件等能量或
作者实现上的普遍结论。

## 9. 停止规则

本轮是冻结的最终独立确认。不得根据这些结果修改 H/P、窗口、载波、子阵、网格、lambda、
alpha 或再增加样本。后续工作只应进行论文排版、公开材料整理和流程偏差披露，不再启动新的
性能寻优或确认 Monte Carlo。
