# Round31 软件正确性修复与有限角度控制结果

日期：2026-09-10。

本轮严格限定为：保留 Round30 六个候选未达标的历史结论，在既有 60 个开发用户上完成一次
标量求解器正确性修复、L06 有限回放、同配置 C/A/B 角度控制和 N=256/L=160 计时修订。
没有生成新用户，没有重跑 Round29 前端，没有启动 600/1000/10000 用户扩展，没有恢复旧
alpha，也没有增加新的载波参数搜索。

## 1. 版本隔离与实际修改

- `+r30`、`+jad`、`+fsjad` 和全部历史结果保持未修改；新实现位于 `matlab/+r31`。
- 标量求解器 `r31.maximizeScore1D` 保留全部已计算网格点、端点、原可行点和有效连续细化点；
  去重时保留同容差组内真实最高评分点，并记录退出状态、严格端点命中和步长相关近边界。
- F/H/P 成本分别改为前端、前端+子空间+角度、前两者+profile；实验会话总计时另列。
- 选型以 `(candidateId, output)` 为独立部署项，先逐项过原门槛，再形成基于归一化风险、
  实际部署时间和等效响应数的 Pareto 集。
- 正式扩展入口新增门禁；诊断候选会抛出 `r31:DiagnosticExpansionRejected`。
- C/A/B 主比较使用完全相同的 41/31/21 分级规则；A/B 不使用 C 的最终解作免费起点。

源码与继承依赖共 132 个 MATLAB 文件的 SHA-256 位于
`matlab/results/full_spectrum/round31_preflight_v2/source_hashes.csv`。

## 2. 软件测试与失败记录

最终本机预检：137 passed、0 failed、0 incomplete，Code Analyzer 0 项。其中新增 Round31
回归 13 项，覆盖已知网格高分保留、近重复高分点、端点最优、非有限细化回退、候选支配
不变量、严格端点与近边界区分、H/P 独立选型反例、扩展门禁、F/H/P 成本、分级二维 MUSIC
一致性、载波列映射、MUSIC 单点/批量评分一致性和数组哈希。

第一次 L06 v1 回放的 60 条结果均在写 SHA-256 时失败：基于线程的 MATLAB worker 不支持
Java 哈希调用。估计后端已经运行，但成功标志为 false；失败目录和日志均保留。v2 将同一
`replay` 对象在主线程生成并哈希，再传给线程 worker；线程烟雾测试和 60 用户完整回放均
通过。该失败是新增审计基础设施问题，不是 MUSIC/profile 数值失败。

## 4. C/A/B 冻结配置

60 个用户为 -10/0/20 dB 各 20 个，seed 和 z/Y 均沿用 Round30 开发设计。60 个 observation
哈希和 60 个 snapshot 哈希均唯一；前端、载波、子阵和子空间均由实际结果/配置校验。

- C：L06 前端；N=256、L=160、P=97、K=2047；二维 41/31/21 MUSIC；初始硬窗口
  ±0.2 deg、±0.0025 m。
- A：与 C 完全相同的载波、补偿、参考子阵、子空间和初始角度域；固定前端距离，只删去
  距离维，角度仍用 41/31/21 分级离散搜索；随后在实际 A 角度重算条件复谱 profile。
- B：只把 A 的载波改为 L06 的 65 个峰值邻域载波；严格按 carrierIndex 映射列。

60/60 均满足 B 是 A 的载波子集、`signalVectors` 对应列逐元素一致和前端精确复用。

## 6. 窗口和边界

C 使用的实际距离硬半窗是 0.0025 m。C 的初始/最终距离网格边界命中分别为 53/60 和
58/60；最终命中在 -10/0/20 dB 为 20/20、20/20、18/20。A/B 的角度最终网格端点命中
均为 0。P_A/P_B 在 ±2 m profile 中的严格端点命中、近边界和端点向外趋势均为 0。

因此本批数据支持“C 的窄距离硬窗强烈约束距离输出，而同配置删去距离维不损失角度”；
不能把边界峰或 profile 改善单独升级为 MUSIC 普遍理论缺陷。

旧 Round30 N=256 计时把 L=160 自动截为 L=128。其增强后端均值 11.0609 s、端到端
17.8937 s 只属于适配版。新的后端在原三个 0 dB 位置上使用 N=256、L=160、P=97，
一次预热、每位置三次正式重复；C 输出与历史精度结果的角度和距离差均为 0。A 的子空间

## 8. 结论边界与下一步选择

本轮软件和接线检查没有发现会推翻 Round29/Round30 历史数值的理论错误。更精确的结论是：

1. Round30 标量求解器存在候选保留缺口，但现有 L06 raw 未受影响。
2. 同配置 A=C 的角度表明，本批角度损失不是“删除距离搜索维”本身造成，而主要随
   2047→65 的载波信息压缩出现。
3. 全载波 P_A 在开发集保持 C 的角度并显著改善距离，成为可考虑冻结的新参考候选；它
   使用 MUSIC 子空间信息和 z 的条件复谱 profile，不是同一信息上的纯目标函数比较。
4. P_A 尚未经过新独立用户验证；当前任务不授权正式扩展，程序门禁保持关闭。
5. 若目标是先验证机制，可在用户确认后为 P_A 预注册全新独立验证；若目标是同时低于公开
   假设基线复杂度，则当前 A/B 均未闭合，必须另起版本研究载波信息保留，而不能在本轮
   事后增加候选或放宽门槛。

物理模型仍沿用既有 `generateTrial/prepareScan/replayRound27Data` 口径。本轮未新增多径、
未知公共时延或同步误差实验，也不能把 z 的 EFIM 当作 z+Y 混合估计器下界；这些限制继续
保留。
