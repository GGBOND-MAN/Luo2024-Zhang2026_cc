# R35 结果汇总与主张审查

本轮为R35探索研究；六个固定几何/SNR工况不构成总体性能或独立优效证据。原P_A、原R34结果及research/01–68均保留。

## 本轮形成的判断

| 问题 | 新增证据 | 当前判断 |
|---|---|---|
| 有限支持与错误峰 | 42组旧数据几何审计；6个候选并集原型结果 | 旧P_A支持已覆盖保存样本；扩域不自动等于改进 |
| 角度不确定性 | 30个有限探针与隐函数公式 | 可以量化局部影响，不能据此启用未经校准的门控 |
| 同步与资源 | 54组局部信息、45组等时长能量配置 | 从条件z/Y补到一个闭合采集模型；同步仍是关键限制 |
| 剩余计算 | 18矩阵、108次正式求解计时、Amdahl分析 | 微基准不足以更换冻结求解器，前端/子空间仍是重点 |
| 条件与公平性 | 24个窗口控制与有限网格证书 | 增强原角度保持结论的适用边界，不扩大为普遍解耦 |

## SAFE

- 所有结果按来源区分：旧R34描述性审计、新6工况开发、确定性理论/信息模型、局部微基准。
- 6/6工况成功，实际输入、哈希、候选、评分面和成本保存；11项MATLAB class-based测试经MCP运行全部通过。
- ±2m覆盖旧1400样本，但未推断总体概率；±0.0025m只归属本地增强基线。
- 新原型保持旧候选的目标不下降，这是一条数值不变量，不是定位性能保证。
- 原方法和材料逐文件保护检查；无原源码替换、无R34统计重算/重选、无自动发布。

## NEEDS QUALIFICATION

- 多中心原型改变支持与网格密度，同时增加评分开销；不是纯窗口单因素的性能结论。
- 所有FIM数字取E/N0=60dB整次训练能量与beta=1，不能与旧每载波SNR图对齐；是新观测模型的局部界。
- scan/array/hybrid三族仅等能量；257时隙分配族才同时控制时长。未证明真实硬件可在全时隙保持相干。
- matrix-free几何评分门槛通过11/18，额外代数压力门槛通过10/18；压力探针不全属于物理导向流形。这既不抹去失败，也不伪称用户定位失败。
- 角度证书仅第一级已计算的有限网格；完整二维计算是生成证据的成本，没有在线加速主张。
- 本轮先发生一次Windows路径分隔符导致的source-path检查失败，发生在生成新输入之前；已修正路径归一化，未改变工况或阈值。日志原样保留。
- case5角度探针出现跳变后，追加的是同一已保存输入上两个既有候选、两个既有角度的4次评分，证实有限候选偏好反转。它是事后机制解释，不是新的独立样本；没有新增优化或改变协议。
- 物理界的显示修正将平面波未知clock的angle可辨识分量与range Inf分开，重复的是确定性信息计算，没有新增随机工况或选择参数。
- Code Analyzer对pilot第128行给1条诊断数组扩展性能提示，属于微基准探针拼接，非估计器错误；不据此修改冻结实现。

## 保留与收束

原P_A仍是原研究的冻结主方法；R35_union_profile与matrix-free只作为未替代基线的研究原型。后续若正式设计新主方法，需要另行固定开发/校准设计，最后再使用未见的独立测试位置。当前任务完成这轮有边界的五方向研究，不自动扩展样本或再次优化。
