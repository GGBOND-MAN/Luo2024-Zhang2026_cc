# Full algorithm

`fsjadFullEstimate` is the frozen high-resolution reference implementation.
Its online parameters are defined only by `fsjadFullConfig`.

Version `FSJAD-Full-513-v1` uses 513 fused carriers, MUSIC grids
`61/41/31`, a 1 m range-profile half-window, 0.1 m profile seeds, and
fixed fusion weight 0.9.
