# 给Claude的任务：P_FALF重尾问题与R56失败后的理论路线选择

日期：2026-09-19

尾部行、降低Gate、重跑R55、增加GH节点、扩大搜索窗口，或在R56上调阈值。目标是选择并严格推导
一个新的R57方向，使最终角度逐行保持P_FA，同时增加稳定、可辨识的距离信息。

## 1. 已冻结方法

### P_A

L06前端 -> L160空间平滑一维MUSIC角度 -> 固定角度exact-q距离profile。P_A是主方法和主攻击依据。

### P_FA

L06前端 -> N256全孔径、每载波自由复增益消元的条件投影角度 -> 与P_A相同的q-only距离profile。
R46 final-1400中角度聚合MSE/P_A约0.4257，七SNR角度优效7/7；距离与P_A工程上接近，但没有
通过预声明2%同时非劣家族。

### P_FALF

最终角度严格等于P_FA。在该角度下将exact-q标量块与Fresnel-Y阵列块的集中似然相加。Y块对每个
载波独立消元复增益alpha_m，因此放弃跨频相干相位，只保留阵列曲率/幅相结构对距离峰的弱排序。

R55 final-1400：

- 七SNR点估计P_FALF/P_A均小于1；
- equal-SNR聚合距离MSE比0.71913，cluster U95=0.84935；
- 七SNR simultaneous 2%非劣家族FAIL；
- top 1%的14行贡献71.1%的绝对配对差和102.7%的净改善；
- 31个大幅移动行贡献绝大部分净收益；
- leave-one-position-out始终小于1，因此不是单个位置主导，而是稀有换峰事件主导。

相对强化Zhang-style基线C_enhanced，R55相同1400行上：

## 2. 已确认的距离瓶颈

R50 oracle-angle诊断表明，在正常局部支持内把真实角度代入同一q-only距离profile，距离MSE几乎
不变。角度误差传导通常只占距离MSE约1e-5至1e-3。因此继续提高角度或对角度做GH边缘化不能解决
距离问题。P_FAM5的零效果与此一致。

Y-only距离明显差于P_A。P_FALF的收益不是Y独立完成距离估计，而是z主导时Y偶尔重排竞争q峰。
这解释了其平均性能好、但方差和尾部不稳定。

## 3. R56假说与固定规则

R56检验q-anchored split-consensus：

1. q-profile先提供最多8个冻结候选盆地；
2. Y不得产生q候选集外的新盆地；
3. Y载波按奇偶位置分成两块；
4. 只有odd-Y、even-Y和full z+Y都选择同一q候选时才允许跨盆地；
5. 否则留在q原选盆地，只做盆地内联合似然细化；
6. 无权重、阈值、SNR规则、学习门控或truth gate；
7. 最终角度逐行等于P_FA。

注意：theta_FA由全部Y估计，所以odd/even评分并非严格独立验证。R56预先只将其称为稳定性约束。

## 5. R56最关键的失败事实

P_FALF在210行中有6个大幅换峰：5个有益、1个有害。R56只允许1个跨盆地换峰，而它恰好是唯一
有害行；全部5个有益换峰均被拒绝。具体为：

- 总共识率84.29%，实际跨盆地共识率0.476%；
- P_FALF条件有害大幅换峰率1/6=16.7%；
- R56条件有害大幅换峰率1/1=100%；
- R56相对P_FALF的聚合MSE恶化69.0%。

这表明odd/even/full一致性不是正确性的证书。低SNR有益换峰的证据本来就弱，拆分后功效更低；
同时各fold共享full-data theta_FA和共同模型失配，使唯一错误模式也能在三者中一致。

- 单纯扩大angle/range窗口；
- R51/R52证书恢复；

## 7. 当前两个候选理论方向

### 方向A：可辨识的低维跨频相位模型

把每载波自由alpha_m替换为公共复增益加公共时延/低阶相位，例如：

\[
\alpha_m=\beta\exp[-j2\pi f_m\tau_{clk}],
\]

并保留传播距离在阵列响应及跨频传播相位中的作用。核心问题是观测总时延通常只含
2r/c+tau_clk，若tau_clk完全未知，则r与tau_clk可能不可辨识。需要明确哪一种附加结构足够：

- 已校准的tau_clk或有界高斯先验；
- 已知距离参考路径；
- 双向测量抵消时钟；
- 多包共享tau_clk且r随已知运动模型变化；
- 多锚点共享硬件时延。

### 方向B：严格cross-fitted有效得分/复合似然

内部将载波分块，用A块估计内部角度、B块计算距离得分，再反向交换并合并；最终仍输出full-data
theta_FA。需要推导插件角度下的有效距离得分或Godambe信息，例如：

\[
s_r^{eff}=s_r-I_{r\theta}I_{\theta\theta}^{-1}s_\theta,
\]

但不能直接假设两fold独立，也不能手调z/Y权重。需说明半载波角度估计损失、模型失配和候选峰离散性
是否使该方案仍然没有足够功效。
